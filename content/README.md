# Public Blog Content

This folder contains ONLY the notes that will be published via Quartz.

## Safety Rules

✅ **ONLY files in this `public/` folder will be published**
❌ **Everything else in your vault stays private**

## Publishing Workflow

1. Write your note anywhere in your private vault
2. When ready to publish, **move or copy** it to `public/`
3. Review and edit for public consumption
4. Run Quartz to build and publish

## Additional Safety

- Files ending with `.draft.md` won't be published (even in this folder)
- Files starting with `private-` or `PRIVATE-` won't be published
- The `.quartzignore` file in the vault root enforces these rules

## Folder Structure

Organize your public content however you like:

```
public/
├── posts/
│   ├── my-first-post.md
│   └── another-post.md
├── about.md
└── index.md
```

## Before Publishing

Always double-check that:
- No personal/private information is included
- Links to private notes are removed or updated
- Images are in the public folder or publicly accessible
